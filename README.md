# Commerce App

Next.js storefront connected to commercetools.

## Run the app

1. Copy `.env.example` to `.env.local`
2. Update environment variables with your commercetools project values
3. Run:

```bash
npm install
npm run dev
```

## Features

- Home page
- Product listing with filters
- Product detail page
- Cart
- Checkout flow
- Customer authentication and account page
- Search page
- Product ratings and customer reviews
